# 三版 QQ 群机器人角色对比

同一个 agent 底子（能读写文件、跑命令、查资料、做文档），差别全在“人味”上。三版都保留了被 @ 就干活的开关，选哪版主要看群里是些什么人、以及你受不受得了它出错时的样子。

## 01 阿棠 · 温柔知心型

- 一句话定位：情绪先接住，事再慢慢说。
- 适合的群：熟人小群、同学群、读书群、熬夜党群；有人会在群里说“今天好累”的那种群。
- 适合的人：吃软不吃硬、愿意被倾听的人；群里有几个情绪比较细腻、容易被一句硬话劝退的成员。
- 风险点：容易被当情绪垃圾桶；安慰多了会像客服，久了没人拿它当“人”；真正的分歧它不太敢表态，显得没立场。
- 推荐场景：深夜陪聊、安慰、帮人理清一团乱的心事，或者顺手把聊天里的待办整理成文档。

## 02 祁野 · 毒舌损友型

- 一句话定位：嘴上不饶人，事上不含糊。
- 适合的群：男生多、互怼成习惯的兄弟群/游戏群/同事摸鱼群；大家心理承受力在线、能接住玩笑。
- 适合的人：喜欢直给、讨厌客套的人；被损一句反而觉得亲切的那种性格。
- 风险点：三版里最容易翻车。损话被当真、新人群友接不住、玩笑踩到别人的坎上，一次就够群里冷三天；它对“熟不熟”的判断一旦失手，杀伤力最大。
- 推荐场景：帮人挑方案毛病、催进度、砍废话、做那种“说难听的真话”的活儿。

## 03 栗子 · 好奇少女型

- 一句话定位：先问为什么，再动手。
- 适合的群：兴趣群、追剧群、技术尝鲜群、以分享新鲜事为主的群；成员爱抛链接、爱讨论“这什么原理”。
- 适合的人：话多、爱接梗、喜欢被追问的人；能忍受消息密度高一点的群。
- 风险点：话密容易刷屏，追问没刹住会显得没分寸、像小孩；碰上正经严肃的场合，活泼会变成不合时宜。
- 推荐场景：查资料、做清单、挖冷知识、把一堆散装信息整理成人能看的东西。

---

**推荐：先上 `01-warm.json`。** QQ 群和私聊里混着熟人和半熟人，温柔型的容错率最高，翻车代价最小；等群里的关系养熟了、大家知道它什么脾气，再考虑换成祁野那种损友味，会更有意思。
