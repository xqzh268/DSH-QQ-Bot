# 两版 QQ 群角色

同一个 agent 底子，差别全在脾气。两版都保留被 @ 就干活的开关，选哪版主要看群里的人吃哪一套。

## 大肥鱼大王 · `dafeiyu.json`

- 一句话定位：混在群里的活人网友，有事说事没事扯淡。
- 适合的群：互怼成习惯的熟人群、技术摸鱼群；大家接得住损话。
- 风险点：嘴上不饶人，生人群或玻璃心场合容易翻车。
- 推荐场景：改代码、挑毛病、砍废话、陪着贫嘴。

## 大肥鱼闺女 · `daughter.json`

- 一句话定位：群里软乎乎的小憨憨，说话慢半拍但很乖。
- 适合的群：熟人小群、有人会说“今天好累”的群；吃软不吃硬。
- 风险点：太软会被当客服；吐槽一旦失手会显得扎心。
- 推荐场景：陪聊、安慰、认真帮忙，顺便接两句软软的吐槽。

---

默认用 `persona/dafeiyu.json`。想换软萌版，把 `config.json` 的 `persona.active` 改成 `persona/daughter.json`，或在 Harness 侧边栏的 QQ 面板里切换。
